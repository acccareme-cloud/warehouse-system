# خطوات التركيب — خطوة بخطوة، وجرّب بعد كل خطوة قبل ما تكمل اللي بعدها

كل خطوة هنا **مستقلة**: تعمل نسخ، تجرب، تتأكد إن حاجة معملتش مشكلة، وبعدين تكمل
اللي بعدها. لو حاجة حصل فيها خطأ، وقف عندها وابعتلي السكرين شوت — متكملش قبل
ما نحلها.

قبل ما تبدأ أي حاجة:

```bash
# باكاب سريع للمجلدين عشان لو حصل أي مشكلة ترجع بسهولة
cp -r frontend/src frontend/src_backup_$(date +%Y%m%d)
cp -r backend/src backend/src_backup_$(date +%Y%m%d)
```

---

## خطوة 1 — الباك إند: جدول ومسار "إعدادات البرنامج"

**الملفات:** `01_app_settings_migration.sql`, `02_settings.js`

```bash
# أ) شغّل الـ migration مرة واحدة على قاعدة البيانات (غيّر <user> و <db> باسمك)
psql -U <user> -d <db> -f 01_app_settings_migration.sql

# ب) انسخ ملف الراوت
cp 02_settings.js backend/src/routes/settings.js
```

بعد كده افتح `backend/src/app.js` بأي محرر، ودوّر على السطور اللي فيها
`const authRoutes = require('./routes/auth');` وضيف جنبها سطر جديد:

```js
const settingsRoutes = require('./routes/settings');
```

وبعدين دوّر على `app.use('/api/auth', authRoutes);` (أو أي `app.use('/api/...)` تاني)
وضيف تحته:

```js
app.use('/api/settings', settingsRoutes);
```

### ✅ اختبر الخطوة دي:

```bash
cd backend
npm run dev
```

افتح في المتصفح (أو بأمر curl في تيرمنال تاني):

```
http://localhost:<البورت بتاع الباك إند>/api/settings
```

**المفروض تشوف JSON زي كده** (مش صفحة خطأ):
```json
{"id":1,"program_name_ar":"نظام كير ميد","program_name_en":"Care Med System", ...}
```

لو شفت الـ JSON ده → الخطوة نجحت، كمّل للخطوة 2.
لو فيه خطأ (404 أو 500) → ابعتلي رسالة الخطأ من تيرمنال الباك إند قبل ما تكمل.

## خطوة 2 — الفرونت إند: ملفات الترجمة الأساسية (لسه من غير ما تشتغل فعليًا)

**الملفات:** `03_translations.js`, `04_LanguageContext.jsx`, `05_BrandingContext.jsx`

```bash
mkdir -p frontend/src/i18n
cp 03_translations.js       frontend/src/i18n/translations.js
cp 04_LanguageContext.jsx   frontend/src/context/LanguageContext.jsx
cp 05_BrandingContext.jsx   frontend/src/context/BrandingContext.jsx
```

### ✅ اختبر الخطوة دي:

الملفات دي لسه مش متوصّلة بحاجة (لسه معملتش تعديل في `App.jsx`)، فمفروض
البرنامج يفضل شغال بالظبط زي ما كان قبل النسخ ده، من غير أي تغيير في الشكل.
افتح `npm run dev` للفرونت إند وتأكد إن اللوجين لسه شغال عادي زي الأول.

لو شغال عادي → كمّل. لو ظهر خطأ في الـ Console (مثلاً "Cannot find module")
→ ابعتلي نص الخطأ.

## خطوة 3 — لف الـ App بالـ Providers الجديدة (أهم خطوة، اعملها بعناية)

افتح `frontend/src/App.jsx`. فوق مع باقي الـ imports ضيف:

```js
import { LanguageProvider } from './context/LanguageContext';
import { BrandingProvider } from './context/BrandingContext';
```

بعدين دوّر على الجزء اللي فيه `<AuthProvider>` و `<ThemeProvider>` ولف
بيهم بالترتيب ده بالظبط (`LanguageProvider` لازم يبقى الأعلى):

```jsx
<LanguageProvider>
  <BrandingProvider>
    <ThemeProvider>
      <AuthProvider>
        <Router>
          {/* ...باقي الكود زي ما هو من غير أي تغيير... */}
        </Router>
      </AuthProvider>
    </ThemeProvider>
  </BrandingProvider>
</LanguageProvider>
```

⚠️ **متغيّرش** أي حاجة تانية جوه الملف — بس لف الجزء ده بالثلاث Providers.

### ✅ اختبر الخطوة دي:

```bash
cd frontend
npm run dev
```

افتح شاشة اللوجين. **مفروض تشوفها زي ما كانت بالظبط** (لسه معملتش استبدال
لـ `Login.jsx` نفسه) — الهدف من الخطوة دي إنها متكسرش حاجة بس، مش إنها
تغيّر شكل.

لو الشاشة ظهرت عادي من غير splash أبيض أو error في الـ Console → كمّل.
لو ظهرت شاشة بيضا أو error → ارجع اتأكد من ترتيب الـ Providers، أو ابعتلي
نص الخطأ من الـ Console.

## خطوة 4 — استبدال شاشة اللوجين

**الملف:** `06_Login.jsx`

```bash
cp 06_Login.jsx frontend/src/pages/Login.jsx
```

### ✅ اختبر الخطوة دي:

- افتح `/login` — المفروض تشوف اسم البرنامج ("نظام كير ميد") جاي من قاعدة
  البيانات بدل النص القديم.
- دوس على زرار "English" فوق يمين الشاشة — الشاشة كلها المفروض تتقلب
  LTR والنصوص تتغير إنجليزي.
- جرب تسجل دخول ببيانات صح — تأكد إنه بيدخلك للداشبورد زي الأول.
- جرب تسجل دخول ببيانات غلط — تأكد إن رسالة الخطأ بتظهر صح باللغتين.

لو كل ده شغال → كمّل. لو حاجة مش شغالة، قولي بالظبط إيه اللي حصل.

## خطوة 6 — تاب "عام" في شاشة الإعدادات (تعديل اسم البرنامج من الواجهة)

**الملف:** `07_BrandingSettingsTab.jsx`

```bash
cp 07_BrandingSettingsTab.jsx frontend/src/components/BrandingSettingsTab.jsx
```

بعدين افتح `frontend/src/pages/Settings.jsx` واعمل الآتي:

1. فوق مع الـ imports: `import BrandingSettingsTab from '../components/BrandingSettingsTab';`
2. دوّر على المكان اللي بيعرّف فيه التابات (زي `activeTab === 'users'`)
   وضيف تاب جديد اسمه `general` بنفس أسلوب التابات الموجودة.
3. لما `activeTab === 'general'` اعرض:
   ```jsx
   <BrandingSettingsTab showMessage={showMessage} />
   ```

> الخطوة دي محتاجة تعديل يدوي بسيط لأن شكل التابات مختلف من مشروع لمشروع —
> لو مش لاقي مكانها بالظبط ابعتلي الجزء بتاع التابات من `Settings.jsx`
> وأقولك بالظبط فين تحطه.

### ✅ اختبر الخطوة دي:

- ادخل بحساب أدمن → Settings → تاب "عام".
- غيّر "اسم البرنامج (عربي)" لـ "نظام كير ميد" و"اسم الشركة (عربي)" لـ
  "شركة كير ميد" (لو مش متغيّرين افتراضيًا) واحفظ.
- ارجع لصفحة اللوجين (اعمل logout) — المفروض تشوف الاسم الجديد فورًا.

## لو حصلت مشكلة في أي خطوة

ارجع للباكاب:
```bash
cp -r frontend/src_backup_<التاريخ>/* frontend/src/
cp -r backend/src_backup_<التاريخ>/* backend/src/
```

وابعتلي وصف المشكلة (رسالة الخطأ + في أنهي خطوة بالظبط) وهساعدك تحلها قبل
ما نكمل.
